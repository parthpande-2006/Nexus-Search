# Nexus Search

An AI-powered document search system built for efficient and intelligent information retrieval.

## Features

- Hybrid search
- Document ingestion and parsing
- FAISS-based vector search
- BM25 keyword search
- LLM-based reranking
- Redis-based processing and caching
- FastAPI backend
- Document access control

## Tech Stack

- Python
- FastAPI
- FAISS
- BM25
- Redis
- PostgreSQL
- SQLAlchemy
- LLMs
